# Decisiones provisionales

Decisiones de negocio o técnicas que un paquete de trabajo tuvo que tomar sin respuesta de José. Se eligió siempre la opción **más restrictiva y más fácil de revertir** (menos permisos, sin datos irreversibles). No son ADR: son supuestos para revisar. Cada fila dice cómo deshacerla.

Cada PR suma sus filas sin tocar las ajenas.
